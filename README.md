# Geode macOS ARM64 — GD 2.2091

An unofficial Apple Silicon build of **Geode 6.0.0-beta.1** for Geometry Dash 2.2091.

Built and tested on an Apple Silicon MacBook Air.

## Download

**[Download Geode for macOS ARM64](../../releases/latest)**

Download the `Geode-arm64.pkg` installer from the latest release.

## Build Information

| Detail | Version |
|---|---|
| Geode | 6.0.0-beta.1 |
| Geometry Dash | 2.2091 |
| Platform | macOS |
| Architecture | ARM64 |
| Compiler | Apple Clang |

## Installation

1. Download the installer from Releases.
2. Back up your Geometry Dash application.
3. Open the `.pkg` file.
4. Follow the installation instructions.
5. Launch Geometry Dash.
